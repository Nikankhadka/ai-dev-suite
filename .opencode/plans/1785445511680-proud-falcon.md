# Plan: Integrate mattpocock/skills into ai-dev-suite

## Overview

Integrate all non-deprecated mattpocock/skills into the ai-dev-suite repo at `~/.config/opencode/` using a git submodule, create OpenCode commands for user-invoked skills, define OpenCode agents, write a one-line `setup.sh`, and ensure agent-agnostic compatibility.

---

## Phase 1: Fork & Submodule Setup

### 1.1 Add git submodule (direct, no fork needed)

```bash
git submodule add https://github.com/mattpocock/skills.git vendor/mattpocock-skills
```

- Creates `.gitmodules` in repo root
- Skills live at `vendor/mattpocock-skills/skills/{bucket}/{name}/SKILL.md`
- **No fork required** — agent-agnostic modifications are applied via a patch script, keeping the submodule pristine and pullable

### 1.2 Update workflow

- `git submodule update --init --recursive` (automatic on clone with `--recursive`)
- To pull upstream changes:
  ```bash
  git -C vendor/mattpocock-skills pull origin main
  ```
- Then re-run the patch script (included in `setup.sh`) to re-apply agent-agnostic modifications

## Phase 6: Symlink Script (`scripts/link-skills.sh`)

Adapts mattpocock's `link-skills.sh` to work with the ai-dev-suite structure:

```bash
#!/usr/bin/env bash
set -euo pipefail

REPO="$(cd "$(dirname "$0")/.." && pwd)"
DESTS=("$HOME/.claude/skills" "$HOME/.agents/skills")
VENDOR_SKILLS="$REPO/vendor/mattpocock-skills/skills"
LOCAL_SKILLS="$REPO/skills"

# Link vendor skills (all non-deprecated buckets)
link_vendor() {
  local bucket="$1"
  for skill_dir in "$VENDOR_SKILLS/$bucket"/*/; do
    [ -d "$skill_dir" ] || continue
    local name="$(basename "$skill_dir")"
    for DEST in "${DESTS[@]}"; do
      mkdir -p "$DEST"
      ln -sfn "$skill_dir" "$DEST/$name"
      echo "  linked $name → $DEST/$name"
    done
  done
}

# Link local skills
link_local() {
  for skill_dir in "$LOCAL_SKILLS"/*/; do
    [ -d "$skill_dir" ] || continue
    local name="$(basename "$skill_dir")"
    for DEST in "${DESTS[@]}"; do
      mkdir -p "$DEST"
      ln -sfn "$skill_dir" "$DEST/$name"
      echo "  linked $name → $DEST/$name"
    done
  done
}

echo "Linking vendor skills..."
for bucket in engineering productivity misc in-progress; do
  echo "  $bucket/"
  link_vendor "$bucket"
done

echo "Linking local skills..."
link_local

echo "Done. Skills linked for Claude Code, OpenCode, and Codex."
```

## Phase 7: setup.sh (One-Line Install)

```bash
#!/usr/bin/env bash
set -euo pipefail

# AI Dev Suite - One-line installer
# Usage: curl -fsSL https://raw.githubusercontent.com/Nikankhadka/ai-dev-suite/main/setup.sh | bash

OPENDIR="${AI_DEVSUITE_DIR:-$HOME/.config/opencode}"
REPO_URL="${AI_DEVSUITE_REPO:-https://github.com/Nikankhadka/ai-dev-suite.git}"

echo "=== AI Dev Suite Installer ==="

# 1. Clone or update repo
if [ -d "$OPENDIR/.git" ]; then
  echo "→ Updating existing repo at $OPENDIR..."
  git -C "$OPENDIR" pull --recurse-submodules
else
  echo "→ Cloning ai-dev-suite to $OPENDIR..."
  git clone --recursive "$REPO_URL" "$OPENDIR"
fi

# 2. Init submodules (idempotent)
echo "→ Initializing submodules..."
git -C "$OPENDIR" submodule update --init --recursive

# 3. Install npm deps
if [ -f "$OPENDIR/package.json" ]; then
  echo "→ Installing npm dependencies..."
  (cd "$OPENDIR" && npm install)
fi

# 4. Patch skills for agent-agnostic compatibility
echo "→ Patching skills for agent-agnostic compatibility..."
bash "$OPENDIR/scripts/patch-skills.sh"

# 5. Link skills for all agents
echo "→ Linking skills for Claude Code, OpenCode, Codex..."
bash "$OPENDIR/scripts/link-skills.sh"

# 6. Verify
echo ""
echo "=== Installation Complete ==="
echo "Skills directory: $OPENDIR/vendor/mattpocock-skills/skills"
echo "OpenCode config:  $OPENDIR/opencode.jsonc"
echo ""
echo "Available commands (run in OpenCode):"
echo "  /tdd       /code-review  /diagnosing-bugs  /grill-me"
echo "  /to-spec   /to-tickets   /implement        /triage"
echo "  /handoff   /teach        /prototype        /wayfinder"
echo "  /ask-matt  /improve-codebase-architecture"
```

Make it executable: `chmod +x setup.sh`

## Phase 8: Agent-Agnostic Modifications (Patch Script)

Changes are NOT committed to the submodule. Instead, a `scripts/patch-skills.sh` applies them after every checkout/submodule update. This keeps the submodule pristine (easy `git pull`) while making skills cross-agent.

### 8.1 `scripts/patch-skills.sh`

```bash
#!/usr/bin/env bash
set -euo pipefail

REPO="$(cd "$(dirname "$0")/.." && pwd)"
SKILLS_DIR="$REPO/vendor/mattpocock-skills/skills"

echo "=== Patching skills for agent-agnostic compatibility ==="

# 1. git-guardrails-claude-code → git-guardrails (rename + generalize)
if [ -d "$SKILLS_DIR/misc/git-guardrails-claude-code" ]; then
  echo "→ Patching git-guardrails-claude-code..."

  # Create agent-agnostic wrapper directory if not already there
  if [ ! -d "$SKILLS_DIR/misc/git-guardrails" ]; then
    mkdir -p "$SKILLS_DIR/misc/git-guardrails"

    # Copy the original SKILL.md as base
    cp "$SKILLS_DIR/misc/git-guardrails-claude-code/SKILL.md" \
       "$SKILLS_DIR/misc/git-guardrails/SKILL.md"

    # Replace Claude-specific name
    # (Using sed -i '' for macOS, sed -i for Linux)
    SED_FLAG=(-i)
    [[ "$(uname)" == "Darwin" ]] && SED_FLAG=(-i '')

    sed "${SED_FLAG[@]}" 's/git-guardrails-claude-code/git-guardrails/g' \
      "$SKILLS_DIR/misc/git-guardrails/SKILL.md"

    sed "${SED_FLAG[@]}" 's|\.claude/settings\.json|the agent settings file|g' \
      "$SKILLS_DIR/misc/git-guardrails/SKILL.md"

    sed "${SED_FLAG[@]}" 's|~/.claude/|~/|g' \
      "$SKILLS_DIR/misc/git-guardrails/SKILL.md"

    # Copy bundled scripts
    if [ -d "$SKILLS_DIR/misc/git-guardrails-claude-code/scripts" ]; then
      cp -r "$SKILLS_DIR/misc/git-guardrails-claude-code/scripts" \
            "$SKILLS_DIR/misc/git-guardrails/"
    fi

    echo "    Created $SKILLS_DIR/misc/git-guardrails/"
  fi
fi

echo "=== Patch complete ==="
```

### 8.2 Skills Requiring Modifications

| Skill | Issue | Patch |
|-------|-------|-------|
| `git-guardrails-claude-code` | Claude-specific name and paths | Create `git-guardrails/` wrapper with generalized references |
| All other skills | Work across agents already | No patches needed |

### 8.3 Summary

Most skills are already agent-agnostic. Only `git-guardrails-claude-code` needs patching. The core engineering skills (tdd, code-review, diagnosing-bugs, grilling) work across Claude Code, OpenCode, Codex, and Cursor without modification. The patch script is idempotent and safe to run after every submodule update.
