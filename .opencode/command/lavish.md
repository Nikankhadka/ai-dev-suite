description: Turn complex or visual agent responses into rich, reviewable HTML artifacts the user can annotate and send feedback on, using the lavish-axi CLI. Use when about to give a plan, comparison, diagram, table, code diff, report, or anything easier to grasp visually than as prose.
agent: planner
---

Run the lavish skill. Generate an interactive HTML artifact for visual review (plans, comparisons, diagrams, tables, code diffs, reports). Open it in the browser with `npx -y lavish-axi <html-file>` so the user can annotate elements, queue prompts, and send feedback back. After receiving feedback, incorporate changes and rebuild.
